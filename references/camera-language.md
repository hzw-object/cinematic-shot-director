# 镜头设计与运镜

先写清观众此刻注意什么，以及画面内已经发生的变化。用演员走位、构图和焦点测试固定机位是否足够。相机移动时，指定动力、方向、起幅、落幅、速度变化和剪辑点。可以用物体掠过、人物停步、视线改变、声音或台词触发运动。

| 想让观众看到什么 | 优先试的构图或运动 | 现场验证 |
| --- | --- | --- |
| 人和地点的距离关系 | 全景、双人同框、纵深走位 | 入口、去路、人物各自的位置能否一眼读出 |
| 台词出口后的真实反应 | 固定近景或带肩机位，给听者停顿 | 不看说话者也能判断这一句改变了什么 |
| 障碍物后的新信息 | 侧向横移，或随人物一步挪出遮挡 | 起幅完全遮住，落幅只揭示该拍需要的信息 |
| 空间感或心理距离在变化 | 物理推近或后撤，指定何时停 | 近处背景的视差、人物大小和焦点都在预期范围 |
| 一次视线或注意力转移 | 转头、摇摄、拉焦或接视点镜头 | 前对象先让位，目标有足够停留时间被认出 |
| 人物与空间同时在变 | 跟拍或演员进出固定画面 | 明确人物路线、遮挡、相机终点和下一个剪接口 |

## 容易混淆的操作

- **摇摄与横移。** 摇摄从固定位置转向，画面左右重新分配。横移改变相机位置，有视差，适合从前景后揭示信息。俯仰与升降同理。
- **推近与变焦。** 推近改变机位和透视。固定机位变焦改变取景范围，同一拍摄位置的透视关系保持一致。手机裁切可改变构图，现场优先确认清晰度与可用空间。写焦距时说明是镜头标称还是全画幅等效。设备未知时，用景别、距离与背景关系表达意图。
- **焦点移动与相机移动。** 拉焦适合在同一构图两层之间转移注意。道具与人脸距离接近、手机可控景深不足时，考虑演员动作或单独的插入镜头。
- **主观镜头与过肩镜头。** 主观镜头应能接上前镜的视线高度和方向。过肩保留人物间距和关系，说明用谁的肩、前景占多少画面，以及被摄者看向哪侧。
- **手持。** 手持可带出贴身跟随、观察或主观感受。指定晃动幅度和目标在画面里的位置。涉及精确道具信息或匹配剪辑时优先保证可读性。

## 把形容词变成拍法

例如雨夜店铺里，一个人听见门外钥匙声。开在收银台侧面中景，门被冷柜遮住一半。金属声响起时先留住人物抬眼，等他停下手里的动作，再随着他向侧边跨一步横移，落幅露出空门把手，停一拍切回他。空间很窄就保留人和门的两个固定机位，用抬眼接门把详情。选择取决于观众是该和人物一起发现，还是先于人物看到门口。

同一镜头需要对比时，只改一个决定，例如固定观察和跟随推近，让用户看到叙事效果、执行成本和可剪性上的差异。剪接相近景别与角度时，检查构图改变是否足以读成新视角，或跳切是否具有明确节奏意图。

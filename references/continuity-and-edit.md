# 连续性与剪辑验收

## 按剪接点检查

挑出信息变化、轴线变化、道具交接、演员进出与版本混剪的关键切点。用 `前镜 → 后镜 | 切前状态 | 切后状态 | 风险证据 | 修复` 记录。动作匹配时标出抓握、接触、停稳或脚落地等明确的匹配点，确保两条素材都有切点前后的动作。跨轴可以有叙事动机，审查重点是处于目标段落的观众能否重新识别方向。

| 常见断点 | 复核方法 | 优先修复 |
| --- | --- | --- |
| 看错方向、人物像在看画外第三人 | 对照俯视图、面部朝向、镜头内的视线和目标位置 | 调整机位或眼线，或用共同画面重新建立位置 |
| 一次动作被做了两次，或者结果无因 | 对照上一镜落幅和下一镜起幅的手、身体、道具位置 | 用重叠动作重切，或用反应/合适的插入镜头让跳变可读 |
| 信息过早泄露 | 检查宽镜、反射、背景以及前置声音是否已经透露 | 调整布置或构图，从关键镜头才露出，给观众识别时间 |
| 道具通过剪接突然换手或变形 | 记录持有人、左右手、方向、开合、破损或磨损等可见状态 | 重取一段连贯动作，或用合适的补镜表达状态变化 |
| 反应被切掉或者对白脱节 | 从上一句播到下一句，确认谁该留在画面、说话声跨哪里 | 让下一场声音先入或上一镜声音延续，保留可读反应与环境底声 |
| 镜头像资料齐全，实际缺一场戏的剪法 | 用主线和最少镜头各剪一遍，逐拍对照必需信息 | 先补缺失的动作结果、反应或可听对白，再做风格性补拍 |

## 按证据决定修复

对已有素材按版本和实际时间码写结果。对计划写镜头 ID 和预计风险。先尝试从现有可用区间重切或用可用声轨修复。需要新增素材时，写清最短补拍/补生成范围、上下游接点、动作复位和验收画面。替换后复查它两边的剪接和整段时长。

按影响给结论。关键剧情缺失、不可执行或必需接点断裂是交付阻塞。能剪出主线但有明确瑕疵时指出代价。风格选择写成可比较的取舍。有条件时用清晰的验收测试表达，如「静音看 12–16 秒仍能识别钥匙最后在谁手里」「从 8 秒开始播放能明白人物朝门还是朝桌走」。含关键声音信息时也单独听声轨，核对对白可懂、声音先后和空间感。

计划文件能核验时间线和关联关系。画面几何、表演、灯光和声音仍以现场或实际素材为证据。

# 电影镜头导演 · Cinematic Shot Director

**给它一场戏，它能把每个镜头拆到机位、走位、起幅、落幅和剪辑点。** 两位演员、一部手机、一盏灯，也能拿到一份按现场条件排好的拍摄单。做 AI 短片时，同一套设计可以直接写成关键帧和动态提示词。

## 一场戏可以拆到什么程度

阿青把钥匙推给阿成，问「你什么时候回来的？」他没伸手，只说「昨晚」。她看一眼门，又把钥匙收回。

在 25 秒方案里，用四个固定机位拍六个剪辑镜头。先用双人全景交代两人和门的位置，再让钥匙从画面左侧滑向桌子中间。听到答案后，镜头留在阿青脸上，看她扫一眼门。切回桌面，钥匙沿原路径被收回。现场先拍完整双人底，再拍两位演员的反打，最后用同一机位补齐钥匙的推、停、收。时间告急时，完整双人底加一条桌面动作就能交代完这场戏。

## 可以交付什么

| 给它什么 | 你会拿到什么 |
| --- | --- |
| 剧本、现场照片、手机或摄影机配置 | 带镜头 ID 的分镜、机位图、演员走位、布光建议、现场拍摄顺序和最少要拍的镜头 |
| 一个需要运镜的情节 | 相机从哪儿开、往哪儿走、何时停、观众在什么时候看到关键信息 |
| 一段参考片或 `rea-video` 报告 | 带时间码的镜头分析，以及适合新人物、场地和设备的拍法 |
| AI 视频创意或已有分镜 | 可独立作图的静帧描述、从起幅到落幅的动态提示词、角色与道具状态 |
| 已有镜头表或粗剪 | 按镜头定位视线、动作、道具和收声衔接问题，修订缺少覆盖的镜头 |

**拍摄顺序和成片顺序用同一套镜头编号。** 摄影和演员知道一条要拍到哪里，剪辑知道哪一秒切、该接哪条素材。光线、声音和道具状态也能按镜核对。

## 安装与试用

使用 `npx` 安装时，请使用 Node.js 22.20.0 或更新版本。

```bash
npx skills add hzw-object/cinematic-shot-director --skill cinematic-shot-director
```

也可把包含 `SKILL.md` 和 `references/` 的完整目录放入 Codex 可发现的 Skills 目录。

> 用 `$cinematic-shot-director` 设计一场 25 秒的厨房双人戏。只有一部手机、一个三脚架和一盏灯。给我镜头表、机位俯视图、拍摄顺序，以及只剩十分钟时必须拍到的素材。

> 用 `$cinematic-shot-director` 把参考片里「横移绕开前景，最后一秒才露出关键道具」的拍法改成咖啡馆里发现一枚钥匙。交付 4 秒镜头的起幅、落幅和动态提示词。

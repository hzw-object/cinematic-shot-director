# 电影镜头导演 · Cinematic Shot Director

**把一场戏设计到现场能拍、后期能剪。** 电影镜头导演从观众看到关键信息的那一刻倒推，决定看谁的反应、机位放哪、运镜何时开始、声音跨过哪个切点。它把导演决策、实拍覆盖、AI 镜头和保底剪法写进同一套镜头编号。

## 一场戏可以拆到什么程度

打烊的咖啡馆里，两个人在桌边交还一把钥匙，第三个人突然进门。观众什么时候发现来人、什么时候看清钥匙，会改变整场戏的紧张感。

**完整方案用四个固定机位和一个两秒的 AI 镜头，剪成 28 秒。** 失去 AI 镜头和两组反打时，完整三人底加桌面特写仍能交代每个必需节拍。示例附机位图、眼线与道具状态、现场顺序、主剪辑和保底剪辑，可用脚本检查时间线。 [查看完整制作示例](references/examples/after-hours.md)

## 可以交付什么

| 给它什么 | 你会拿到什么 |
| --- | --- |
| 剧本、现场照片、手机或摄影机配置 | 导演处理、机位图、演员走位、按条件排的拍摄单、可独立剪出的保底版本 |
| 一个需要运镜的情节 | 相机从哪儿开、往哪儿走、何时停、观众在什么时候看到关键信息 |
| 一段参考片或 `rea-video` 报告 | 带时间码的镜头分析，以及适合新人物、场地和设备的拍法 |
| AI 视频创意或实拍素材 | 静帧描述和动态提示词、参考素材映射、跨镜道具状态和实拍接点 |
| 已有镜头表或粗剪 | 按时间码定位轴线、动作、道具和声音问题，给当前素材可执行的重切和最短补拍范围 |

**拍摄顺序和成片顺序用同一套镜头编号。** 摄影和演员知道一条要拍到哪里，剪辑知道哪一秒切、该接哪条素材。光线、声音和道具状态也能按镜核对。

## 自动检查两条剪辑时间线

正式交接可选择 JSON 清单。随附的 Python 3 脚本可检查镜头与机位引用、时间间隙和重叠、目标时长，以及主剪辑和保底方案声明的必需节拍覆盖。通过后可导出 CSV。

```bash
python3 scripts/check_plan.py references/examples/after-hours.plan.json --csv timeline.csv
```

现场执行和素材质量可按 [剪辑验收手册](references/continuity-and-edit.md) 复查。

## 安装与试用

使用 `npx` 安装时，请使用 Node.js 22.20.0 或更新版本。

```bash
npx skills add hzw-object/cinematic-shot-director --skill cinematic-shot-director
```

也可把包含 `SKILL.md` 和 `references/` 的完整目录放入 Codex 可发现的 Skills 目录。

> 用 `$cinematic-shot-director` 设计一场 25 秒的厨房双人戏。只有一部手机、一个三脚架和一盏灯。给我镜头表、机位俯视图、拍摄顺序，以及只剩十分钟时必须拍到的素材。

> 用 `$cinematic-shot-director` 把参考片里「横移绕开前景，最后一秒才露出关键道具」的拍法改成咖啡馆里发现一枚钥匙。交付 4 秒镜头的起幅、落幅和动态提示词。
